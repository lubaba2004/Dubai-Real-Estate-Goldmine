# 🏙️ Dubai Real Estate Goldmine  
### UAE Rental Price Prediction using Machine Learning

## 📌 Project Overview
This project focuses on analyzing and predicting **rental property prices across the United Arab Emirates (UAE)** using machine learning techniques.  
The dataset includes listings from major cities such as **Dubai, Abu Dhabi, Sharjah, Ajman, Ras Al Khaimah, Umm Al Quwain, and Al Ain**, sourced from real estate platforms.

The goal of this project is to:
- Perform **Exploratory Data Analysis (EDA)**
- Build and compare multiple **regression models**
- Select the **best-performing model**
- Predict rental prices based on property features

---

## 🧠 Problem Statement
Accurately estimating rental prices is crucial for:
- Real estate investors  
- Property owners  
- Tenants  
- Market analysts  

This project aims to **predict rental prices** using historical property data and machine learning algorithms.

---

## 📂 Dataset Information
**Source:** bayut.com  
**Type:** Real estate rental listings  

### Key Features:
- City  
- Property Type  
- Bedrooms  
- Bathrooms  
- Area (sqft)  
- Furnishing Status  
- Rental Price (Target Variable)

- Support Vector Regressor (SVR)

---

## 🏆 Model Performance
The models were evaluated using **R² Score** on both training and testing datasets.

**Best Model:**  
➡️ **Random Forest Regressor**  
- High accuracy  
- Low overfitting  
- Strong generalization on test data

---

## 📊 Results & Insights
- Rental prices are strongly influenced by **location, property size, and number of bedrooms**
- Tree-based models performed better than linear models
- Ensemble models provided the most stable predictions
